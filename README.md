# Applied Statistical & Data Modeling in R

A hands-on reference for statistical and machine-learning modeling in R, built
around worked examples and real case studies.

## 📊 View the report (live)

### 👉 https://fe42526037646.github.io/applied-statistical-modeling-r/

The report is an interactive HTML document rendered from R Markdown. **Open the
link above to read it.** Clicking `index.html` here in the repository only shows
the raw source — GitHub does not render HTML files in the file view, so the live
page above is where the report actually opens.

## What's inside

- **Probability distributions** and the idea of likelihood
- **Simple linear regression** — estimation, inference, and diagnostics
- **Multiple linear regression** — Mahalanobis and Cook's distance, polynomial
  and interaction terms
- **Model selection** — best-subset, forward, and backward stepwise
- **Machine learning** — regularization (glmnet), trees and ensembles (rpart,
  random forest, gbm), and neural networks
- **Count models** — Poisson and negative-binomial regression
- **Case studies** on real data, including Brazilian inflation (IPCA) and
  greenhouse-gas emissions
